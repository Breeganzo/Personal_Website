## 🎯 Quick Start

### Local Development

1. **Clone the repository**
```bash
git clone https://github.com/Breeganzo/Personal_Website.git
cd Personal_Website
```

2. **Open in browser**
```bash
# Simply open index.html in your browser
# OR use Live Server in VS Code
# OR use Python's built-in server
python -m http.server 8000
```

3. **View the site**
Navigate to `http://localhost:8000` or open `index.html` directly

### No Build Process Required!
This is a static website - no npm install, no webpack, no build steps. Just open and run!

## 🎨 Customization

### Update Profile Information
Edit `index.html`:
- Line 48-52: Profile section
- Line 62-94: About section
- Line 98-252: Experience section
- Line 256-430: Projects section

### Modify Colors
Edit `style.css`:
- Primary gradient: `#667eea` → `#764ba2`
- Change in lines: 203-205, 347-349, etc.

### Add Projects
1. Add project image to `assets/`
2. Update `index.html` projects section
3. Follow existing project card structure

## 🌐 Deployment

### GitHub Pages (Recommended)

1. **Push to GitHub**
```bash
git add .
git commit -m "Initial commit"
git push origin main
```

2. **Enable GitHub Pages**
   - Go to repository Settings
   - Navigate to Pages
   - Select `main` branch
   - Save

3. **Access your site**
   - URL: `https://[yourusername].github.io/Personal_Website/`

### Alternative Hosting
- Netlify: Drag and drop deployment
- Vercel: Connect GitHub repo
- AWS S3: Static website hosting
- Azure Static Web Apps: Integrated deployment
